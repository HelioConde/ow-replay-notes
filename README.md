# OW Replay Notes

**Projeto em concepção para Overwatch.** Anotar e revisar decisões importantes de partidas assistidas em replay.

## Experiência proposta

Criar notas por partida, categorizar erros e registrar ações de melhoria.

## Status: ideia documentada

O repositório contém apenas o README nesta revisão. **Não existe aplicação jogável, frontend publicado ou integração de dados implementada aqui.**

## Próximo marco

Definir estrutura de notas e referências de tempo para a revisão.

Depois, criar um MVP pequeno e validá-lo com jogadores antes de adicionar integrações e estatísticas avançadas. Dados de partidas, se usados, devem respeitar as permissões das plataformas e suas limitações.

## Organização

O planejamento do portfólio fica no [Ideias IA Lab](https://github.com/HelioConde/ideias-ia-lab); o futuro código do produto deverá permanecer aqui.

*Projeto independente, sem afiliação oficial com os titulares do jogo.*
